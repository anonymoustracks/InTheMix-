# GlideMix promo kit

One text for every sale: Black Friday, Cyber Monday, Christmas, New Year, Easter, summer, birthday, or a
random weekend. Fill in the `{BRACKETS}`, pick the version for where you post, and run the checklist first.

## 0. Checklist before ANY promo goes out

- [ ] **Price vs code.** Codes are a fixed amount off. €40 off only makes sense on €89. While the Beta price
      (€49) is live, €40 off sells GlideMix for €9. Check the Polar price first.
- [ ] The code exists in Polar, is limited to GlideMix, and its start/end dates match the post. Polar's end
      date is the START of that day: to run through 10 Dec, end on 11 Dec.
- [ ] Buy once with the code yourself (or in Polar's test mode) and see the right total.
- [ ] Every price in the post is real: "normally €89" only if €89 is the actual price before and after.
- [ ] The end date is in the post. No fake countdowns, no "last chance" that isn't.
- [ ] Brand words: rekordbox, djay lowercase (never start a sentence with them). Never write Camelot. Other
      apps only as "works with" or "in the tradition of", never as a claim about them.
- [ ] Pictures: song names blurred.

## 3. SEO rules (for every post)

1. **Name + what it is in the first line.** Always "GlideMix" together with "DJ mixing software" (or
   "DJ software", "mixtape software"). Search engines and AI answers learn what GlideMix is from these pairs.
2. **The phrases people search**, used naturally, two or three per post: *DJ mixing software*, *mixtape
   software*, *DJ software for Mac*, *DJ software for Windows*, *timeline DJ software*, *radio show
   software*, *MixMeister alternative*.
3. **Title under 60 characters**, deal and name in it, the occasion word (Black Friday, Christmas…) near the
   front. People search "black friday DJ software".
4. **One clean link**: https://glidemix.com/download. No `.html`, no `www`.
5. **A price, a date and "free demo"** in every version. Specific posts are quoted and ranked; vague ones aren't.
6. **Picture alt text** says what's on it: "GlideMix DJ mix on a timeline", not "image1".
7. **Same facts everywhere.** Price, code and end date identical on the website, KVR, Discord and social.
8. **Never copy one text word for word to several sites.** Change the first two sentences (version C for
   forums, B for news sites). Search engines prefer the original and may hide copies.
9. **Website:** add the sale to the home page and download page; keep the page addresses the same
   (no special sale page that disappears and leaves a dead link).
